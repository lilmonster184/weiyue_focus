# 微阅Focus

一个面向网页阅读的第三方增强扩展，为 `weread.qq.com` 提供更完整的阅读区控制。

本项目不是腾讯或微信读书官方产品，也没有获得其授权或背书。`微信读书`、腾讯及相关标识归其各自权利人所有。

## 功能

- 阅读区全屏：只将阅读内容区域扩展到全屏，支持 `Esc` 退出。
- 滚动阅读：全屏后仍可使用鼠标滚轮、选中文本、划线、批注、翻译和写想法。
- 双栏阅读：保留微信读书原有的双栏阅读布局和交互。
- 阅读背景：白纸、护眼、纸质、羊皮、雾蓝、暖灰六种背景。
- 静止隐藏鼠标：全屏静止约 1.8 秒后隐藏光标，移动鼠标或操作页面后恢复。
- 轻量实现：只在匹配的阅读页面运行，不使用远程脚本、统计服务或广告。

## 安装

### 加载已解压的扩展程序

1. 下载或克隆本仓库。
2. 打开 Chrome 的 `chrome://extensions/`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本仓库根目录。
5. 打开或刷新 `https://weread.qq.com/web/reader/` 阅读页面。

### 使用发布包

下载 `release` 目录中的 ZIP 后解压，再按上面的步骤加载解压后的文件夹。Chrome 的“加载已解压的扩展程序”需要选择文件夹，而不是直接选择 ZIP。

## 使用方式

安装后，阅读页右侧工具栏会出现全屏按钮和阅读背景按钮。全屏按钮使用四角图案；背景按钮打开颜色选择面板。背景选择会自动保存到当前微信读书网页的本地存储中。

按 `Esc` 可以退出全屏。全屏状态下，页面内容仍由微信读书自己的阅读交互处理，扩展只调整阅读区域的布局和样式。

## 数据与权限

- 清单没有申请额外的 Chrome 权限，也没有 `host_permissions`。
- 内容脚本只匹配 `https://weread.qq.com/web/reader/*`。
- 扩展不读取或上传账号信息、Cookies、书籍内容、笔记、划线、浏览历史或剪贴板。
- 扩展不连接自己的服务器，不包含远程代码、广告、分析统计或用户画像。
- 仅使用微信读书网页自身的 `localStorage` 保存阅读背景值。键名为 `wr-reader-reading-background`，值只会是 `white`、`eye`、`paper`、`parchment`、`mist`、`stone` 之一。

详细内容见 [隐私政策](PRIVACY.md)。

## 兼容性

面向桌面 Chromium 浏览器开发，建议使用 Chrome 105 或更高版本。Edge、Brave、Vivaldi 等 Chromium 浏览器通常也可用，但未逐一保证。移动端浏览器和 Firefox 不在当前测试范围内。

微信读书网页的 DOM 结构或阅读实现发生变化时，扩展可能需要更新适配。
