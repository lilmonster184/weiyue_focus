微阅Focus

适用于微信读书网页版的第三方阅读工具，与腾讯及相关产品无关联。

安装
1. 打开 Chrome 的扩展管理页：chrome://extensions/
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本文件所在的 weread-reader-fullscreen 文件夹。
4. 如果已经安装过旧版本，先在扩展管理页点击旧扩展的刷新按钮，再刷新微信读书阅读页。
5. 进入阅读页后，点击右侧最下方的四角图标。

使用
右侧工具栏最下方会出现与其他工具一致的白色圆形按钮，使用 `fullscreen-icon.svg` 四角图案，不显示文字。点击后，阅读区进入全屏，浏览器顶部和 Windows 底栏都会隐藏；滚动阅读模式仍可用鼠标滚轮上下滚动，选中的文字与高亮、批注框和“写想法”编辑框会保持在同一位置。全屏静止约 1.8 秒后鼠标会隐藏，移动鼠标、滚动或按键会立即显示。按 Esc 退出全屏，也可以再次点击按钮退出。

阅读背景
全屏按钮上方会新增一个纸页图标。点击后可选白纸、护眼、纸质、羊皮、雾蓝和暖灰六种阅读背景；选择会自动记住。普通双栏阅读只改变正文阅读框；滚动阅读会填满与顶栏等宽的居中阅读框，页面两侧留白和顶栏保持微信读书原样；全屏时背景会铺满阅读区。

兼容性
滚动阅读会保留微信读书自己的画布选区逻辑；对“强制开启网页文本选择”的外部扩展，只限制微信读书的画布层，避免干扰划线、批注和翻译，也不会影响其他阅读区元素。

说明
此扩展只匹配 https://weread.qq.com/web/reader/ 页面，不读取、不上传书籍内容，也不需要额外权限。
